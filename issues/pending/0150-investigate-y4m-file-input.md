## 目的

iOS SDK で y4m ファイルを映像入力として読み込み、配信できるかを調査してノウハウとしてまとめる。可能であればサンプルに組み込む。

## 現状

- `SoraTests` に E2E テスト用のダミー映像を生成する仕組み（`DummyVideoCapturer`）があり、物理カメラを使わずに映像を送信できる。ただしテストターゲット内に閉じており、サンプルからは利用できない
- SDK にテスト注入用のダミー音声デバイス（`DummyAudioDevice`）がある
- y4m ファイルを読み込んで映像入力にする仕組みは SDK にもサンプルにもない
- y4m は主に検証用途で使われる非圧縮の映像フォーマットである

## 設計方針

- y4m ファイルを読み込んで映像フレームに変換し、既存の映像送信経路に載せられるかを調査する
- 実現する場合の実装先を、SDK 本体・サンプル・テストのどれにするかを整理する
- 既存のダミー映像で代替できないユースケースがあるかを確認する

## pending にした理由

既存のダミー映像・ダミー音声で検証用途の多くを代替でき、y4m 読み込みの優先度は高くない。実現可能性と具体的な用途を整理できていないため pending とする。

## 解決方法

## Pending 解除条件

- y4m ファイル読み込みでしか得られない検証用途があるかを確認する。
- 用途がある場合は、実装先（SDK 本体・サンプル・テスト）と実現方法を決めて対応する。
