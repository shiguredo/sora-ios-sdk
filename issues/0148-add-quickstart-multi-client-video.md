# クイックスタートで複数クライアントから受信した映像を描画できるようにする

- Created: 2026-09-11
- Completed:
- Branch: feature/add-quickstart-multi-client-video
- Polished:

## 目的

sora-ios-sdk-quickstart で複数クライアントから受信した映像を同時に描画できるようにする。クイックスタートを SDK の複数クライアント間の映像送受信の検証に使えるようにするため。

## 現状

sora-ios-sdk-quickstart には受信用の `VideoView` が 1 つしかなく、`onAddStream` で受信ストリームごとに同じ `VideoView` を `videoRenderer` に設定している。このため最後に追加されたストリームの映像しか表示されず、複数クライアントの映像を同時に確認できない。

sora-ios-sdk-samples の VideoChatSample はアプリ上で設定を変更するための UI を備えているが、コードを少し書き換えて再ビルドするクイックスタートのほうが検証しやすい場合がある。

## 設計方針

- 複数の受信ストリームを並べて描画する UI をクイックスタートに追加する
- 受信ストリームの追加と削除に追随して表示を更新する
- 単一クライアント接続時の既存の挙動は維持する

## 完了条件

- クイックスタートで複数クライアントから受信した映像を同時に描画できること
- 単一クライアント接続時の挙動が変わらないこと
